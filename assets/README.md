# YCCCI Assets Directory

You can place your official high-resolution logo here:
- **Filename**: `yccci-logo.png`
- **Location**: `assets/yccci-logo.png`

The website automatically detects if `assets/yccci-logo.png` is present and will display it in the header, left column, and cinematic intro sequence. If not found, it seamlessly falls back to the Google Stitch emblem.
